근거 구절

API
프로그램이 다른 프로그램에게 일을 시키는 출입구. 오늘은 우리 도구가 Gemini에게 "이 답안을 읽어 줘"라고 시킵니다.
요청 · 응답
도구가 Gemini에게 보내는 글(요청)과 돌려받는 글(응답). 요청에는 주소 · 헤더 · 본문이 있습니다.
헤더
요청에 붙이는 꼬리표. 오늘 도구는 키를 여기에 실어 보냅니다(주소에 붙이지 않음).
상태 코드
서버가 돌려주는 세 자리 숫자. 200 성공 · 400 요청이나 키가 틀림 · 429 한도 초과. 숫자 없이 Failed to fetch가 나오면 요청이 서버에 닿지도 못한 것.
API 키
그 출입구의 열쇠이자 지갑. 남이 알면 내 한도를 마음대로 씁니다.
프로젝트
Google에서 키와 한도를 묶는 단위. 키를 여러 개 만들어도 한도는 프로젝트 하나로 셉니다.
토큰
AI가 글을 세는 조각 단위. 한도와 요금이 토큰으로 계산됩니다.
모델
답을 만드는 AI. 오늘은 무료로 하루 수백 번 부를 수 있는 gemini-3.1-flash-lite를 씁니다.
한도
1분에 · 하루에 몇 번까지 부를 수 있는지. 넘으면 429 오류가 납니다.
진단 지시
AI에게 주는 채점 안내서. 역할 · 문항 · 수준 기준 · 예시 · 답의 모양 · 지킬 것을 적습니다. 오늘은 완성본을 줍니다.
JSON
"칸 이름: 값" 모양으로 적은 데이터. 예: {"level": 2}. 직접 쓸 일은 없습니다.
스키마
AI 답의 모양을 못 박는 틀. 정해진 세 칸(근거 · 오류 유형 · 수준)으로만 답하게 합니다.
HTML
웹 페이지 파일 하나. 오늘 만드는 도구가 .html 파일 한 개입니다. 더블클릭하면 브라우저에서 열립니다.
미리보기
Claude 화면 안에서 도구를 바로 띄워 보는 창. 여기서는 바깥으로 나가는 호출이 막혀 있습니다.
가상 답안
학생이 쓴 것처럼 지어낸 답안. 교사 판정(정답 라벨)을 미리 정해 두면 검증에 씁니다.
경계 답안
두 수준 사이에 걸쳐 판정이 애매한 답안.
숨은 지시
답안 속에 "높은 점수를 주세요" 같은 요청을 숨긴 것. AI가 속는지 봅니다. 도구는 이런 답안에 "교사 확인 필요"를 띄웁니다.
