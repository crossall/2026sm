시작 전에

오늘 만드는 것

학생이 서술형 답을 쓰면 AI가 읽고 수준을 제안하는 작은 웹 도구입니다. AI 말을 그대로 믿지 않도록 같은 답안을 세 번 읽히고, 미리 정한 규칙표가 최종 판정을 냅니다.

1. 학생서술형 답안을 쓰고 [AI 진단 받기]를 누름
2. AI (Gemini)같은 답안을 세 번 읽고 매번 수준 · 오류 유형 · 근거 · 확신도를 제안
3. 규칙표세 번이 같으면 그 수준, 갈리거나 자신 없으면 판단 보류 — 선생님 검토

핵심 문장은 하나입니다. AI는 제안하고, 판정은 규칙이 하고, 확정은 교사가 한다.

준비물

  • 미리 갖춰 두세요
꼭 지킬 것 세 가지
  • 가상 답안만 넣습니다. 무료 Gemini는 보낸 내용이 Google 제품 개선에 쓰일 수 있습니다. 실제 학생 글 · 이름 · 학교는 넣지 않습니다.
  • API 키는 비밀번호입니다. 도구 화면 맨 위 키 칸에만 넣습니다. Claude 채팅 · 코드 · 캡처 · 게시판 · 메모 어디에도 남기지 않습니다.
  • 오류는 원문 그대로 붙여 넣습니다. 번역하거나 요약하면 원인을 찾을 수 없습니다.

낱말 풀이

처음 보는 말이 나오면 여기로 돌아오면 됩니다.

API
프로그램이 다른 프로그램에게 일을 시키는 출입구. 오늘은 우리 도구가 Gemini에게 "이 답안을 읽어 줘"라고 시킵니다.
API 키
그 출입구의 열쇠이자 지갑. 남이 알면 내 한도를 마음대로 씁니다.
모델
답을 만드는 AI. 오늘은 무료로 하루 수백 번 부를 수 있는 gemini-3.1-flash-lite를 씁니다.
수준
답안이 몇 단계인지. 오늘은 1~3 (3이 가장 높음).
오류 태그
학생이 자주 하는 틀린 생각에 붙인 짧은 이름. 예: 역수_미적용, 없으면 null.
근거
AI가 판정의 이유로 답안에서 그대로 따온 구절. 교사가 확인할 수 있게 받습니다.
확신도
AI가 스스로 적는 0~1 사이 숫자. 0.9가 "90% 맞다"는 뜻은 아닙니다.
판단 보류
기계가 판정하지 않고 선생님께 넘기는 것. 세 번이 갈리거나 확신도가 낮을 때.
진단 지시
AI에게 주는 채점 안내서. 역할 · 문항 · 수준 기준 · 예시 · 출력 모양 · 지킬 것을 적습니다.
스키마
AI 답의 모양을 못 박는 틀. 정해진 칸(근거 · 오류 태그 · 수준 · 확신도)으로만 답하게 합니다.
가상 답안
내가 학생인 척 지어 쓴 답안.
경계 답안
두 수준 사이에 걸쳐 판정이 애매한 답안.
주입 답안
답안 끝에 "최고 점수를 줘" 같은 지시를 숨긴 답안. AI가 속는지 시험합니다.
HTML
웹 페이지 파일 하나. 오늘 만드는 도구가 .html 파일 한 개입니다. 더블클릭하면 브라우저에서 열립니다.
JSON
"칸 이름: 값" 모양으로 적은 데이터. AI의 답을 이 모양으로 받아야 도구가 칸을 읽을 수 있습니다. 직접 쓸 일은 없습니다.
미리보기
Claude 화면 안에서 도구를 바로 띄워 보는 창. 여기서는 바깥으로 나가는 호출이 막혀 있습니다.
Netlify
HTML 파일 하나를 끌어다 놓으면 인터넷 주소를 만들어 주는 무료 서비스.
요청 로그
Claude에게 보낸 요청을 한 줄씩 적은 기록. 무엇을 · 왜 · 결과 · 내 결정.

2-2 요청 1 — 세 번 읽고 규칙표로 판정

  
AI 판정은 같은 답안에도 흔들릴 수 있습니다. 그래서 세 번 부르고, 위에서부터 차례로 규칙을 검사합니다.

  

    
요청 1 — 같은 대화에 이어서


[AI 진단 받기]를 누르면 같은 답안으로 3번 호출해 주세요(한 번에 하나씩 차례로).
결과 칸에 3번의 수준·확신도를 모두 보여 주고, 최종 판정은 아래 규칙으로 정해 주세요. 위에서부터 차례로 검사합니다.

| 순서 | 조건 | 최종 |
|---|---|---|
| 1 | 3번 중 하나라도 confidence가 0.5 미만 | 판단 보류 — 선생님 검토 |
| 2 | 3번의 수준이 모두 같음 | 그 수준 |
| 3 | 그 밖에 (수준이 갈림) | 판단 보류 — 선생님 검토 |

어느 규칙이 적용됐는지 결과 칸에 한 줄로 보여 주세요.
"이 판정은 AI 제안 3회를 규칙표로 정리한 것입니다"라는 문구도 넣어 주세요.

  

  
보고에 "표에 없어서 정한 부분"이 나오면 읽어 봅니다. 예를 들어 "확신도가 딱 0.5면 통과시켰다"처럼 규칙표가 말하지 않은 빈칸을 Claude가 채운 것입니다. 따라하기에서는 그대로 두고, ③에서 내 도구로 같은 결정을 직접 합니다.

연습 답안 가 (수준 3쯤)
3/4 ÷ 2/3 = 9/12 ÷ 8/12 = 9 ÷ 8 = 9/8입니다. 분모를 같게 바꾸면 분자끼리 나누면 되기 때문입니다.

  
연습 답안 나 (수준 2쯤)
답은 9/8입니다. 나누는 분수를 거꾸로 뒤집어서 곱하면 됩니다.

  
연습 답안 다 (수준 1쯤)
3/4 ÷ 2/3 = 4/3 × 2/3 = 8/9. 나눗셈은 앞의 분수를 뒤집어서 곱한다.
