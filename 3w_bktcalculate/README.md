# BKT 계산기

베이즈 지식 추적(BKT)의 네 모수를 정하고 응답을 하나씩 주면, **“지금 이 개념을 아는가”의 확률**이 어떻게 갱신되는지 —
그리고 그 확률로 **어떤 처방과 피드백이 나가는지** 계산하는 웹앱입니다.

「적응형 학습과 AI 프로그래밍」(숙명여자대학교 교육공학과, 2026-2) 3주 실습 도구.
모형 근거: Corbett, A. T., & Anderson, J. R. (1995). *Knowledge tracing*. UMUAI, 4(4).

1. `index.html` 을 브라우저로 열면 끝입니다. 서버도 설치도 필요 없습니다.
2. 처음 열면 기본값(P(L0) 0.30 · P(T) 0.10 · P(G) 0.20 · P(S) 0.10)이 들어 있습니다.
   전부 O로 두었을 때 **0.693 → 0.919 → 0.983, 3번째에서 숙련**이 나오면 정상입니다.

로컬에서 주소를 띄워 보려면 (선택):

```bash

npm test         # 계산이 맞는지 확인 (47개 항목)
```

```
├── test/
│   └── bkt-core.test.js    계산이 맞는지 확인하는 검증 코드 (47개 항목)

```

**`assets/bkt-core.js` 가 이 앱의 핵심입니다.** 화면 코드가 하나도 없어서,
그대로 떼어다 다른 곳에 붙일 수 있습니다. 11주 시스템을 만들 때 이 파일을 가져다 쓰시면 됩니다.

```js
// 브라우저에서
<script src="bkt-core.js"></script>
BKT.run({L0:.3, T:.1, G:.2, S:.1, mastery:.95}, [true, false, true]);

// Node 에서
const BKT = require("./bkt-core.js");
BKT.attemptsToMastery({L0:.3, T:.1, G:.5, S:.1, mastery:.95});   // → 6
```

## 무엇을 계산하는가

### 갱신 (탭 1)

갱신은 두 단계입니다. 앱의 「한 걸음씩」 표가 이 두 단계를 나눠서 보여 줍니다.

1. **되돌아보기** — 응답을 보고 “아까 아는 상태였을 확률”을 다시 계산합니다 (베이즈).
   맞혔으면 `P(L)(1−S) / [P(L)(1−S) + (1−P(L))G]`, 틀렸으면 `P(L)S / [P(L)S + (1−P(L))(1−G)]`
2. **학습 반영** — 아직 모르는 몫에 학습률을 곱해 더합니다. `P + (1−P)T`
   시도 자체가 배울 기회였기 때문입니다. 그래서 틀려도 확률이 조금은 올라갑니다.

### 비교와 민감도 (탭 2)

P(G)만 바꿔 두 조건을 나란히 돌립니다. 기본값에서 **P(G) 0.2는 3문제, 0.5는 6문제**입니다.
문항 형식이 곧 모수라는 것을 숫자로 보는 자리입니다.

### 규칙표 (탭 3)

진단 결과별로 처방과 피드백을 정하는 다섯 줄입니다. 실습 2의 산출물이고,
11주에 이 표가 그대로 조건문이 됩니다.

**규칙 시험기**가 이 탭의 핵심입니다. P(L)을 0.42로 고정하고 관측 수만 2 → 5로 바꿔 보십시오.
확률은 그대로인데 걸리는 규칙이 **5번(판단 보류 · 문항 추가)에서 3번(선수 개념으로 내려감)으로** 바뀝니다.
처방이 반대 방향입니다. 확률만 저장하면 이 구분을 할 수 없습니다 —
**확률과 관측 횟수를 같이 보관하십시오.**

## 알아 두면 좋은 것

### 증거의 세기는 확률 변화폭이 아닙니다

“오답이 정답보다 무겁다”는 말을 확률 변화폭으로 확인하려 하면 헷갈립니다.
P(L)이 0.3일 때는 정답이 더 크게 움직이고(+0.393 vs −0.154), 0.9일 때는 오답이 더 크게 움직입니다(+0.078 vs −0.324).

변화폭이 “지금 확률이 어디에 있느냐”에 달려 있기 때문입니다.
그래서 **승산(odds)** 으로 봅니다. `BKT.evidence()` 가 그 값을 로그 승산으로 돌려줍니다.

기본 모수에서 정답은 승산을 4.5배 올리고 오답은 8배 내립니다. **오답이 1.4배 무겁습니다.**
이 비는 P(L)과 무관합니다. P(S)가 작을수록 커집니다.

### 퇴화 모델

P(G) + P(S) ≥ 1 이면 “모르는 학생이 아는 학생보다 잘 맞힌다”는 뜻이 되어 모형의 해석이 뒤집힙니다.
앱이 경고를 띄우지만, 추정 알고리즘은 이것을 막지 않습니다. 예측 오차만 줄이기 때문입니다.
**추정이 끝나면 모수를 눈으로 확인하십시오.**

### 저장되는 곳

입력한 내용은 브라우저의 localStorage에 남습니다. 그 브라우저에만 남고 서버로 가지 않습니다.
다른 사람에게 넘기려면 **「링크 공유」**(내용이 주소에 통째로 담깁니다) 또는 **「파일 저장」**을 쓰십시오.
