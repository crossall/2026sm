# 로그에서 결정까지

학습 로그(CSV)를 **지표**로 줄이고, 지표 표와 화면 스케치의 위젯마다 **“이 위젯이 바꾸는 결정”**을 한 줄씩 붙이는 웹앱입니다.

「적응형 학습과 AI 프로그래밍」(숙명여자대학교 교육공학과, 2026-2) 4주 실습 도구입니다. 4주 주제는 학습 분석과 대시보드입니다.
이 주차의 규칙은 한 줄입니다. **위젯 하나에 결정 하나. 그 결정을 말할 수 없으면 뺍니다.**

---

## 바로 써 보기

1. `index.html`을 브라우저로 열면 됩니다. 서버를 띄우거나 무엇을 설치할 필요가 없습니다.
2. 처음 열면 배포한 가상 로그(269줄 · 학습자 25명 · 개념 C·E·F)가 들어 있습니다.
   **개념 C 반 평균 0.65 · 0.5 미만 9명 · 0.9 이상 8명**이 보이면 정상입니다.

로컬 주소로 띄우거나 계산을 검증하려면 (선택):

```bash
npm start        # http://localhost:5174
npm test         # 계산이 맞는지 확인 (68개 항목)
```

## 탭 다섯 개

| 탭 | 강의에서 | 하는 일 |
|---|---|---|
| 지표 계산 | M4 시범 | 피벗 두 번(숙련 확률 · 관측 수)과 겹쳐 읽기, 평균 vs 분포, 규칙별 발동, 먼저 가야 할 학생, 선수 개념 역전 |
| 실습 1 · 지표 표 | 실습 1 | 결정부터 적고 지표·계산을 채우기. 결정 칸이 비었거나 “파악·확인”뿐이면 표시함 |
| 실습 2 · 화면 스케치 | 실습 2 | 학습자 화면·교사 화면의 위젯과 결정 주석. 저해상도 와이어프레임이 바로 그려짐 |
| 실습 3·4 · 준거틀 · 뺀 것 | 실습 3·4 | 준거틀 선택과 근거, 뺀 위젯, 관측 부족 표시 방법 |
| 정리 | 제출 | 네 가지 산출물과 한 줄 답 두 개를 LMS에 붙여 넣을 글로 모음 |

적은 내용은 **이 브라우저에만** 저장됩니다(localStorage). 다른 기기로 옮겨지지 않습니다.

## 격자 한 칸은 세 상태 중 하나

| 상태 | 조건 | 화면 |
|---|---|---|
| 판단 가능 | 관측 3회 이상 | 숙련 확률을 다섯 단계 색으로, 칸 안에 숫자 |
| 관측 부족 | 관측 3회 미만 | **빗금 + 관측 수(n2)**. 확률 값이 있어도 색으로 칠하지 않음 |
| 시도 없음 | 그 개념 문항을 안 풂 | 빈 칸 |

관측 부족을 낮은 숙련과 같은 색으로 칠하면 3주 규칙표의 5번 줄(판단 보류)이 화면에서 사라집니다.

## 다른 로그 넣기

머리글의 **로그 바꾸기**를 눌러 CSV 파일을 끌어다 놓거나 내용을 붙여 넣으십시오.

- 반드시 있어야 할 칸: `learner_id` `skill` `p_known_after` `n_obs`
- 있으면 쓰는 칸: `item_id` `correct` `streak` `rule_fired`. `streak`가 없으면 `correct`로 계산하고, `rule_fired`가 없으면 3주 규칙표 기본값(숙련 0.95 · 중간 0.50 · 관측 3회 · 연속 오답 3회)으로 계산합니다.
- 계산은 모두 브라우저 안에서 이루어지며, 파일은 어디로도 전송되지 않습니다. **실명이 든 파일은 넣지 마십시오.**

## 파일 구조

```
.
├── index.html              화면 구조
├── assets/
│   ├── styles.css          디자인 (2·3주 웹앱과 같은 토큰 · 다크 모드 포함)
│   ├── la-core.js          ★ 계산 로직 — 화면과 무관한 순수 함수
│   ├── app.js              화면 그리기와 사용자 조작
│   └── sample-log.js       배포 가상 로그 CSV 원문 (file://에서도 열리도록)
├── test/la-core.test.js    계산 검증 (68개 항목)
├── netlify.toml · package.json
```

`la-core.js`는 10주에 데이터베이스에서 같은 지표를 뽑을 때 그대로 참고할 수 있습니다.

```js
var L = LA.loadLog(csvText);            // 읽기 + 빠진 칸 계산
var g = LA.grid(L.rows);                // 개념 × 학습자 격자 (마지막 값)
LA.distribution(g, "C");                // 평균 · 10구간 분포 · 관측 부족 제외
LA.ruleCounts(L.rows, "final");         // 지금 상태 기준 규칙별 발동
LA.priority(g);                         // 먼저 가야 할 학생 (연속 오답 → 관측 부족)
```

## 데이터에 대해

배포 로그는 강의용으로 **생성한 가상 데이터**입니다. 2주 분수 나눗셈 지식 구조에 3주 BKT(L0 .30 · T .10 · G .25 · S .12)와 규칙표를 적용해 만들었습니다.
실제 학생 데이터가 아니므로 논문이나 보고서의 실증 자료로 쓰지 마십시오.
