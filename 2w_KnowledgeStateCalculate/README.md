# 지식 상태 계산기

지식 구성요소(KC)와 선수관계를 넣으면 **가능한 지식 상태**와 각 상태에서 **지금 배울 수 있는 것(outer fringe)** 을 계산하는 웹앱입니다.
Q-matrix 탭에서는 가상의 학생 응답으로 어떤 개념이 의심되는지 진단해 볼 수 있습니다.

「적응형 학습과 AI 프로그래밍」(숙명여자대학교 교육공학과, 2026-2) 2주 실습 도구.
이론 근거: Doignon & Falmagne (1985). *Spaces for the assessment of knowledge*.

## 코드를 읽는 순서

처음 읽는 분께 권하는 순서입니다.

1. **`ks-core.js` 의 `compute()`** — 2ⁿ가지 조합을 전부 만들어 보고, 선수 조건을 어기는 것을 걸러냅니다.
   여기 한 함수에 이 앱의 아이디어가 다 들어 있습니다.
2. **`outerFringe()`** — “지금 배울 수 있는 것”을 어떻게 찾는지. ALEKS가 매번 계산해 보여 주는 목록입니다.
3. **`diagnose()`** — Q-matrix로 결손 개념을 좁혀 가는 규칙.
4. **`app.js` 의 `renderLattice()`** — 계산 결과를 그림으로 옮기는 부분.

### 지식 상태를 정수 하나로 나타내는 방법

이 코드는 집합을 **비트마스크**로 다룹니다. A=1, B=2, C=4, D=8 … 로 두면
`{A, C}` 는 `1 + 4 = 5` 입니다. 그러면 집합 연산이 정수 연산 한 번으로 끝납니다.

```js
s >> j & 1      // j번째가 s에 들어 있는가
s | (1 << j)    // s에 j를 넣은 집합
s & ~(1 << j)   // s에서 j를 뺀 집합
(pre[j] & ~s)   // j의 선수 조건 중 s에 없는 것들 — 0이면 조건을 다 갖춘 것
```

## 기능

- **격자 그림** — 아는 것이 적은 상태를 아래에, 많은 상태를 위에. 선 하나가 구성요소 하나만큼의 차이입니다.
  칸을 누르면 그 상태의 outer fringe·inner fringe·경로 수를 봅니다.
- **PNG 저장** — 격자를 그림 파일로. 실습 제출물 ① “지식 구조 그림 1장” 에 그대로 쓸 수 있습니다.
- **링크 공유** — 입력한 내용이 통째로 주소에 담깁니다. 게시판에 붙이면 상대가 열어서 그대로 봅니다.
- **파일 저장·열기** — `지식구조.json` 으로 내려받고 다시 불러옵니다. 기기를 옮길 때 씁니다.
- **표 복사** — 상태 목록을 탭 구분 텍스트로. 문서에 붙이면 표로 들어갑니다.
- **인쇄 / PDF** — 인쇄용 스타일이 따로 들어 있어 종이나 PDF로 깔끔하게 나옵니다.
- **순환 감지** — A→B, B→A 처럼 서로를 가리키면 경고합니다.
  이 경우 `{A,B}` 는 형식상 조건은 만족하지만 **하나씩 배워서는 도달할 수 없습니다**(경로 수 0). 그 구분까지 잡아냅니다.
- 다크 모드, 키보드 조작, 화면 낭독기 대응.

입력 내용은 **브라우저에만** 저장됩니다(localStorage). 서버로 아무것도 보내지 않으므로
학생 데이터가 밖으로 나가지 않습니다. 대신 다른 기기에서 이어 하려면 링크 공유나 파일 저장을 쓰십시오.

## 수업에서 쓰는 방법

**6주 (Netlify 배포)** — 이 폴더가 곧 배포 실습 재료입니다. 학생이 자기 계정에 올려 보고
주소가 생기는 것을 확인하면, 11주 프로젝트 배포는 같은 절차의 반복입니다.

**11주 (시스템 제작)** — 이 앱에는 **도메인 모델**만 있고 학습자 모델과 교수 모델이 없습니다.
학생 프로젝트는 여기에 나머지 둘을 붙이는 일이라고 보면 됩니다.

### 학생용 확장 과제 (난이도 순)

1. 구성요소 수를 8개에서 10개로 늘리기 — `CODES` 와 `compute()` 의 반복 범위를 보십시오.
   2¹⁰ = 1,024가지라 아직 순식간에 끝납니다. 20개(백만 가지)로 늘리면 어떻게 되는지도 재 보십시오.
2. 상태마다 “여기서 시작하면 끝까지 몇 걸음인가”를 표시하기.
3. 문항을 자동 추천하기 — 지금 후보 상태가 여러 개일 때, 그중 절반을 갈라 주는 문항 고르기(적응형 검사의 원리).
4. 학습자 모델 붙이기 — 안다/모른다 대신 0~1 확률로 두고, 응답마다 갱신하기 (3주 지식 추적).
5. Supabase 연결 — 지금은 브라우저에만 저장합니다. 여러 학습자의 기록을 남기려면 서버가 필요합니다 (9주).
